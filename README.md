# Blood Donation Network and Emergency Matching Platform

## 60-Day Capstone Project

### Domain
HealthCare / Blood Donation Management System

### Objective
Build a web application that connects blood donors, patients, hospitals, and blood banks. The system enables donors to register, allows patients or hospitals to create emergency blood requests, automatically matches eligible donors based on blood group and availability, and helps administrators manage users, blood requests, and donation activities efficiently.

### Technology Stack

- Frontend: React.js, HTML, CSS, JavaScript
- Backend: Spring Boot (Java)
- Database: MySQL
- Authentication: Spring Security + JWT
- API Testing: Thunder Client / Postman
- Version Control: Git & GitHub
